OPTION B: USE FULL MySQL VERSION (Production)


Step 1: Fix MySQL Authentication
   a) Open Command Prompt as Administrator
   
   b) Stop MySQL:
      net stop MySQL80
   
   c) Start with skip-grant-tables:
      mysqld --skip-grant-tables
   
   d) Open new Command Prompt, run:
      mysql -u root
   
   e) In MySQL prompt, paste these lines one by one:
      FLUSH PRIVILEGES;
      ALTER USER "root"@"localhost" IDENTIFIED BY "root";
      CREATE DATABASE library_db;
      EXIT;
   
   f) Close both command prompts
   
   g) Restart MySQL:
      net start MySQL80

Step 2: Update .env file
   Open: c:\Users\acer\library_management_system\.env
   
   Replace with:
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=root
   DB_NAME=library_db

Step 3: Run Application
   Open PowerShell in: c:\Users\acer\library_management_system
   
   Run:
   python library_management.py

Step 4: Use the App
   - Select "1. Register" to create account
   - Select "2. Login" to login
   - Follow the menu prompts

 PART 7: TROUBLESHOOTING


Problem: "Module not found" error
Solution: Run: pip install -r requirements.txt

Problem: MySQL connection error
Solution: 
  1. Check MySQL is running: Get-Service MySQL80
  2. Verify .env credentials
  3. Use demo.py instead (no MySQL needed)

Problem: "Port already in use" (if using MySQL)
Solution: MySQL already running on port 3306 (this is OK)

Problem: Database errors
Solution: Delete library_demo.db and run demo.py again
