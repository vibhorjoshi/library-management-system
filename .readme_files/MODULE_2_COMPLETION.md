## What's Implemented

### 1. Core Payment Features ✅

```python
# Auto-calculate fines at Rs. 2/day
calculate_overdue_fine(issued_book)

# Create/update fine records
create_or_update_fine(issued_book=issued_book)

# Create Stripe PaymentIntent
create_payment_intent(amount=50, description="Fine", metadata={})

# Verify payment succeeded

```

### 2. REST API Endpoints ✅

| Method | Endpoint | Purpose | Auth |
|--------|----------|---------|------|
| POST | `/api/payments/create-intent/` | Initiate payment | JWT |
| POST | `/api/payments/confirm/` | Confirm payment | JWT |
| GET | `/api/fines/` | List user's fines | JWT |
| GET | `/api/fines/{id}/` | Get fine details | JWT |
