4. DATABASE SCHEMA (7 Tables)


users
  - user_id (PRIMARY KEY)
  - username (UNIQUE)
  - password_hash (bcrypt hashed)
  - email (validated format)
  - role (student/librarian/admin)
  - created_at (TIMESTAMP)

books
  - book_id (PRIMARY KEY)
  - title, author, isbn (UNIQUE)
  - category
  - total_copies, available_copies
  - published_year
  - created_at

issued_books
  - issue_id (PRIMARY KEY)
  - user_id (FOREIGN KEY)
  - book_id (FOREIGN KEY)
  - issue_date, due_date, return_date
  - status (issued/returned/overdue)
  - fine_amount

reservations
  - reservation_id (PRIMARY KEY)
  - user_id, book_id (FOREIGN KEYS)
  - reserved_at, status

fines
  - fine_id (PRIMARY KEY)
  - user_id, issue_id (FOREIGN KEYS)
  - amount, reason
  - paid, paid_at

notifications
  - notification_id (PRIMARY KEY)
  - user_id (FOREIGN KEY)
  - message, type
  - is_read, created_at

7. HOW TO RUN


OPTION 1: Demo Version (Recommended for testing)
  Command: python demo.py
  No setup needed
  Works instantly with SQLite
  Demonstrates all core functionality

OPTION 2: Full MySQL Version
  Step 1: Configure MySQL
    - Windows Admin CMD: net stop MySQL80
    - Start skip-grant: mysqld --skip-grant-tables
    - Connect: mysql -u root
    - Run SETUP_GUIDE.txt commands
    - Restart: net start MySQL80
  
  Step 2: Update .env with MySQL credentials
  
  Step 3: Run: python library_management.py
  
  Step 4: Register new user or login
